The Storage component is responsible for managing all data persistence operations. It handles saving contact data to a local JSON file and loading it back when the application starts.

### **Error Handling Strategy**

The storage system employs a multi-layered error handling approach:

1. **File I/O Errors:** Handles permission issues and file access problems
2. **JSON Parsing Errors:** Recovers from malformed JSON with detailed logging
3. **Data Validation Errors:** Skips invalid entries while preserving valid data
4. **Duplicate Entries:** Automatically removes duplicates during loading

## **Contributions to the User Guide (Extracts)**

### **Automatic Data Saving**

ElderRing automatically saves your contact data after every operation. Your data is stored in a JSON file that you can manually edit if needed.

### **Data File Location**
- **Windows:** `data/addressbook.json`
- **macOS/Linux:** `data/addressbook.json`

### **File Format Example**
```json
{
  "persons": [
    {
      "name": "Alice Yeoh",
      "phone": "87438807",
      "email": "alice@example.com",
      "address": "Blk 30 Street 29",
      "remark": "Likes coffee",
      "tags": ["friends", "colleagues"]
    }
  ]
}
```

### **Error Messages Explained**

- **`Duplicate entry skipped`:** Contact with same name and phone already exists
- **`Invalid entry skipped`:** Missing required fields or invalid data format
- **`Data loading completed`:** Summary of successful data loading operation

### **Enhanced Find Command**

Find contacts using partial name matching:
- `find al` will find "Alice", "Alan", "Albert"
- `find smith` will find "John Smith", "Jane Smithsonian"

*Note: The find command is case-insensitive and matches any part of the name.*
